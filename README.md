# JT. Maker's Catalog

최종택의 개인 포트폴리오이자, 직접 만들고 출시한 제품을 모아 둔 카탈로그입니다.

- 출시 앱은 출시 상태와 지원 플랫폼을 표시하고 각 프로젝트 상세로 연결합니다. 가격이나 무료 이용 범위를 일괄적으로 표시하지 않습니다.
- 제작자 소개에는 협업 가능 시점을 명시합니다. 현재 안내는 2027년 3월부터이며 구체적인 일정은 이메일로 문의할 수 있습니다.
- 블로그에는 제품을 만들고 운영하며 남긴 기록을 쌓습니다.

## 문구 원칙

쇼핑몰 분위기는 카탈로그 구성과 시각 디자인으로 표현합니다. 앱 설명은 사용자가 할 수 있는 일을 중심으로 쓰고, 제작자를 상품에 빗댄 매진·품절 표현은 사용하지 않습니다.

## 기술 구성

React · TypeScript · Vite · Tailwind CSS · React Router

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

GitHub Pages 배포를 위해 Vite base path는 `/profile/`로 설정되어 있습니다.
